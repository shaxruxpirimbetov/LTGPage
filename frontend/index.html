В разработке
Как это работает

От пустого поля до ссылки — три шага

Никакой настройки сервера: весь процесс проходит через API сервиса.

01

Регистрация и токен

Создаёшь аккаунт и получаешь пару JWT-токенов — доступа и обновления.

POST /api/user/
POST /api/token/
02

Отправка HTML

Передаёшь заголовок, короткое описание и саму HTML-разметку страницы.

POST /api/page/
{ title, description, html }
03

Публичная ссылка готова

Страница сразу доступна по адресу вида /view/<id>/ — можно делиться где угодно.

GET /api/page/view/241/
Для разработчиков

Простое REST API поверх твоих страниц

Все действия в кабинете — это тонкая обёртка над теми же эндпоинтами, которые доступны напрямую.

POST
/api/page/
Создать новую страницу. Требует токен доступа.
GET
/api/page/
Список всех опубликованных страниц.
PATCH
/api/page/<id>/
Обновить страницу. Доступно только владельцу.
GET
/api/page/view/<id>/
Отдаёт сырой HTML страницы — то, что видит посетитель.
POST
/api/token/
Получить пару JWT-токенов по логину и паролю.
create_page.js 
// создаём и публикуем страницу одним запросом
const res = await fetch("https://dawletyar.pythonanywhere.com/api/page/", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": `Bearer ${accessToken}`
  },
  body: JSON.stringify({
    title: "Промо-страница",
    description: "Скидка 20% на первый заказ",
    html: "<h1>Привет!</h1>"
  })
});

const page = await res.json();
// page.id → адрес: /api/page/view/{page.id}/
